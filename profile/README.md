## 🎯 战队简介

我们来自 **肇庆学院**，参加全国大学生机器人大赛 **RoboMaster 机甲大师赛**，队名 **Foray**。

战队现有 **算法组**（视觉识别、导航定位）与 **电控组**（嵌入式控制、硬件调试）等技术小组，工作覆盖机械、电控、视觉、导航与运营方向。
